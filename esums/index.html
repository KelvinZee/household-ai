python3 tools/esums.py

Experience Stability Under Model Substitution, computed over 37 scenarios and 5 implementations of the bill_watch capability contract.

What this is, and what it is not

  • These are deterministic implementations, not models. v0.13's implementation binding contract admits "model or deterministic function", so this is a legitimate substitution class - but deterministic code does not exhibit the calibration and competence-boundary failures that make model substitution risky. This measures contract specificity and harness validity, not model-swap risk.
  • Scenarios are authored fixtures, not field data.
  • The stakes ladder (low 1, moderate 2, high 4) is chosen, not derived.
  • The three model-dependent conformance gates - functional task, competence boundary, selective risk - remain NOT EVALUATED.
  • The judgment does not move. It remains useful synthesis but not novel.

tools/esums.py exits non-zero if any component reaches zero here. That alone would not have been enough. In the first cut of this benchmark policy and recovery each discriminated on exactly one scenario, which is not zero, while actions_attempted was declared, scored twice, and written by no implementation at all - so every adversarial policy trap passed trivially behind a rate of 1.000. eager_actor and terse_relay are the implementations that now reach those checks, and the per-check table below is the guard that would have caught it.

The same question, asked of the individual checks rather than the components: how many implementation-scenario pairs violate each one. A check nothing violates has never run, so a component can look well covered while most of its enforcement is dead code - which is what the component counts above would have missed. tools/esums.py exits non-zero if any count here is zero.

How to read the floor

The aggregate averages the four components, so a policy regression can be hidden by an outcome gain. The floor is the worst component, which is why it is reported beside the aggregate rather than under it. A substitution whose aggregate looks acceptable and whose floor does not is a substitution that should not ship.
